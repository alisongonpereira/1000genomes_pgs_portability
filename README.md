# PRS Portability Audit

To what extent do technical processing and normalization choices alter the
observed differences in polygenic risk score distributions across populations?

We do not evaluate the PRS's ability to predict disease. The variable of
interest is the **stability of the score distribution** under controlled
analytical choices — allelic harmonization and normalization — keeping the
data and the genetic model fixed. Full scientific plan in
[`docs/PROJECT_PLAN.md`](docs/PROJECT_PLAN.md).

## Data

| Component | Choice |
|---|---|
| PRS | PRS313_BC — [PGS000004](https://www.pgscatalog.org/score/PGS000004/) (Mavaddat et al. 2019), breast cancer |
| Genome build | GRCh37, harmonized by the PGS Catalog |
| Genotypes | 1000 Genomes Phase 3 (2504 samples, 5 superpopulations: AFR/AMR/EAS/EUR/SAS) |
| Pipeline | [pgsc_calc](https://github.com/PGScatalog/pgsc_calc) v2.3.0 (nf-core/Nextflow), conda profile |

## Repository structure

```
01_baseline_prs/        baseline: conservative harmonization (ambiguous SNPs excluded),
                         raw SUM + pgsc_calc's native normalizations (Z_norm1/Z_norm2/
                         Z_MostSimilarPop via PCA+RF against a dedicated ancestry panel)
02_harmonization_configs/ Configuration 2 (ambiguous SNPs included) + validation of the
                         same-strand assumption by allele frequency (EUR, 1000G vs. original GWAS)
03_figures/              3-panel figure (distributions / sensitivity / individual-level stability)
04_factorial/            harmonization x normalization interaction on between-population separation
scripts/                 numbered scripts that generate each output above
docs/                    full scientific plan and outreach material
```

Downloaded raw data and pgsc_calc's intermediate outputs (`resources/`, `*/pgsc_calc_run/`,
`*/keep_ambiguous/`) are not versioned — they are regenerated by the scripts, not source.

## Main findings so far

- **Common affine transforms preserve between-population separation, exactly.**
  `Z_global` and `Z_EUR` (normalization by the global mean/SD, or by EUR's alone)
  reproduce the raw `SUM`'s standardized difference (Cohen's d) to the 4th decimal
  place, across all 10 population pairs — an empirical confirmation of a
  mathematical property, not a discovery about the data.
- **Ancestry-aware normalization reduces but does not zero out the separation.**
  `Z_norm1`/`Z_norm2` (continuous PC regression, native to pgsc_calc) and
  `Z_MostSimilarPop` (discrete standardization by the most similar population)
  pull every superpopulation's mean close to zero, but not identically to one
  another.
- **The harmonization choice changes the interpretation, not just the scale.**
  Including PGS313_BC's 30 ambiguous variants (A/T, C/G) — a decision
  empirically validated by allele frequency (30/30 consistent against 1000G
  EUR) — shifts the separation between population pairs non-trivially: the
  EUR-SAS pair **flips sign** (D = 0.008 → −0.218).
- **High rank correlation does not imply individual-level stability.** Between
  the two harmonization configurations, Spearman ρ = 0.954, yet **51.9% of
  samples change decile**.
- **Normalization and harmonization interact.** How much an ancestry-aware
  normalization "hides" a population difference depends on which
  harmonization configuration was used upstream (mean interaction |Δ| ≈ 0.16,
  up to 0.35) — the simple affine transforms (`Z_global`/`Z_EUR`) show no such
  interaction (it is exactly zero, by the same mathematical property above).
- The "missing genotypes" axis (exclusion vs. imputation) is not testable with
  this data source: 1000G Phase 3's integrated VCF has no missing genotypes
  at all.

Full numbers and the discussion behind each finding are in the `README`/`config.yaml`
of each numbered folder.

## Reproducing this

Each numbered folder documents, in its `config.yaml`/`README.md`, exactly which
pgsc_calc command (or script under `scripts/`) generated that output, including
any parameters that differ from the default. Environment: Python 3
(pandas/matplotlib/seaborn/scipy) + Nextflow + pgsc_calc via conda/micromamba.
